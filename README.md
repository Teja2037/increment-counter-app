# Increment Values Web Application

A simple and interactive web application developed using HTML, CSS, and JavaScript. The project allows users to increment a displayed value by different amounts through button clicks, demonstrating fundamental concepts of JavaScript event handling and DOM manipulation.

## Features

* Display an initial value of `0`
* Increment value by +1
* Increment value by +2
* Increment value by +5
* Increment value by +10
* Dynamic value updates without page refresh
* Simple and user-friendly interface
* Lightweight and fast-loading application

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## How to Run

1. Download or clone the repository.
2. Open `increment.html` in any modern web browser.
3. Click any increment button to update the displayed value.

## Purpose

This project was developed to practice front-end web development concepts such as JavaScript event handling, DOM manipulation, dynamic content updates, and user interaction using HTML, CSS, and JavaScript.
